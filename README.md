Прозрачный оверлей клавиш для стримов и записи игр: W, A, S, D, Space, Shift, Ctrl, ЛКМ и ПКМ.

Скачай key_overlay.exe и запусти. Python не нужен.

Insert — меню настроек (цвета, прозрачность, положение)
F8 — перемещение оверлея мышью
F9 — выход

Программа отслеживает только эти клавиши и кнопки, ничего не записывает и не отправляет в интернет. Исходный код открыт.
Если Windows или антивирус предупреждает о запуске — это ложное срабатывание, связанное с отслеживанием клавиш.
